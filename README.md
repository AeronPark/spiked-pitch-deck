# SPIKED Pitch Deck

Professional investor pitch deck for SPIKED - Liquid Courage performance hard seltzer.

## Files

- `index.html` - Main pitch deck presentation
- `styles.css` - Professional styling and animations
- `export-to-slides.html` - Instructions for exporting to Google Slides

## Quick Start

1. **View the deck**: Open `index.html` in Chrome
2. **Navigate**: Use arrow keys or scroll
3. **Full screen**: Press F11 for presentation mode

## Export to Google Slides

### Method 1: PDF Import (Recommended)
1. Open `index.html` in Chrome
2. Print to PDF (Ctrl+P)
   - Layout: Landscape
   - Margins: None
   - Background graphics: ON
3. In Google Slides: File → Import slides → Upload PDF

### Method 2: Screenshot Each Slide
1. Open deck in full screen (F11)
2. Screenshot each slide
3. Insert into Google Slides as images

- Use 16:9 aspect ratio in Google Slides
- Add subtle transitions between slides
