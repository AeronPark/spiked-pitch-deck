SPIKED Pitch Deck - Export Instructions

Your SPIKED pitch deck is ready! Here's how to get it into Google Slides:

Option 1: Quick Screenshot Method

  1. Open the pitch deck HTML file in your browser
  2. Press F11 to enter full screen mode
  3. Use Page Down to navigate through slides
  4. Take a screenshot of each slide (Win+Shift+S on Windows or Cmd+Shift+4 on Mac)
  5. Create a new Google Slides presentation
  6. Paste each screenshot into a slide

Option 2: Print to PDF Method

  1. Open the pitch deck HTML file in Chrome
  2. Press Ctrl+P (or Cmd+P on Mac)
  3. Set destination to "Save as PDF"
  4. Layout: Landscape
  5. Margins: None
  6. Save the PDF
  7. Go to Google Slides and create a new presentation
  8. File → Import slides → Upload the PDF

Option 3: Professional Export

  1. Open the pitch deck in Chrome
  2. Install the "Full Page Screen Capture" extension
  3. Capture each slide as a high-res image
  4. Use Google Slides template with 16:9 aspect ratio
  5. Insert images as backgrounds for each slide
  6. Add any animations or transitions you want

Google Slides Tips

  • Use Master Slides to maintain consistent branding
  • The color codes for SPIKED brand:
    • Lime: #c8ff00
    • Blue: #00b8ff
    • Pink: #ff2d6e
    • Orange: #ff9a00
    • Black: #050505
  • Font: Use Arial or Helvetica for consistency
  • Add slide transitions for professional presentation
